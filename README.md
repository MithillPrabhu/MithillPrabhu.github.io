# mithillprabhu.github.io

Personal portfolio of **Mithill Prabhu**, Robotics & Automation Engineer.

**Live site:** https://mithillprabhu.github.io

## About the site

- A single self-contained `index.html` (HTML, CSS and vanilla JavaScript), with no frameworks, libraries or build step
- Light and dark themes, a responsive layout from 320px phones to large desktops, and support for reduced-motion settings
- An interactive line-drawing robot arm in the hero section that you can drag; it uses two-link inverse kinematics to follow the gripper
- SEO metadata, Open Graph share card, JSON-LD profile data, `sitemap.xml` and `robots.txt`

## Structure

```
index.html          the portfolio page
404.html            "page not found" page
assets/og-image.png link preview image for LinkedIn, WhatsApp and X
sitemap.xml         sitemap for search engines
robots.txt          crawler rules
```
